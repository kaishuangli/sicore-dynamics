# SiCore Dynamics Website V0.3

This is a runnable Next.js demo for the SiCore Dynamics homepage.

## What changed in V0.3

- Enlarged and replaced the header logo with the official SiCore Dynamics brand logo.
- Added a header-optimized transparent horizontal logo asset.
- Increased navigation height and visual brand presence.
- Upgraded the Hero section with stronger wireless-power visual language.
- Added subtle CSS animation for the hero image, energy beam, and power ring.
- Improved SEO/GEO logo reference in JSON-LD schema.
- Kept the white + blue + black premium technology style approved in V0.2.

## Run locally

```bash
cd sicore-dynamics-v0.3
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Notes

This version is focused on visual direction, brand presence, navigation, Hero, capability cards, industry preview, SEO/GEO foundation, and overall homepage style.
